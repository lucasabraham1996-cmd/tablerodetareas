Tipos de acción · color de la tarjeta

Aparecen dentro de cada tarjeta y se pueden cambiar con un clic. Podés crear los tuyos. El rojo está reservado para Urgente y tareas vencidas.

Categorías

Podés modificar el color y elegir cualquier icono disponible de Lucide escribiendo su nombre, por ejemplo: clipboard-list, database, trophy o calendar-days.

Estados

Rojo = Urgente y queda reservado para ese estado. Los demás estados pueden personalizarse sin usar rojo.

Subestados sugeridos

Estas opciones aparecen como sugerencias en el formulario de tareas, pero igualmente podés escribir uno nuevo manualmente.

Firebase y recordatorios

Firebase ya está cargada. El correo y WhatsApp quedan como destinatarios; para envíos automáticos fuera de la app hace falta crear una función de servidor.
La app queda preparada para usar Firestore como almacenamiento cuando cargues una configuración válida.
Configuración avanzada para envíos automáticos
Este campo no es un dato que ya tengas: es la dirección de una función que debe crearse para enviar correos y WhatsApp aunque la app esté cerrada. Podés dejarlo vacío por ahora; las alertas flotantes dentro de la app funcionan igual.

Acceso rápido para crear una tarea

El acceso directo abrirá esta app y mostrará automáticamente el cuadro de Nueva tarea.

En iPhone

  1. Abrí el enlace especial con Safari.
  2. Presioná el botón Compartir.
  3. Elegí Agregar a pantalla de inicio.
  4. Usá el nombre “Nueva tarea”.
iPhone exige confirmar manualmente la incorporación a la pantalla de inicio; una página web no puede crear el icono sin esa confirmación.
